# TY HD Renderer: fix plan, 2026-10-16

Source: docs/PLAN_3DAY_20261016.md (sections 5-9), todo.json open items, and the shader-pack ranking in docs/research/minecraft_shaderpack_port_ranking.md.

Reading of "agree to all of them": the owner accepts the proposed defaults in PLAN_3DAY section 10 (A: Ultra uses stable High-style plus safe extras, old Ultra kept as experimental in ini only; B: batch 1 first; C: footprints by texture clamp first; E: ship v0.3.3 after batch 1+2 with one playtest), and the Minecraft-ranking order (tonemap, shadow-edge bias, TAA filter only if needed).

Rules that apply to every item (from the plan, section 2): max 3 agents at once; one game at a time; the game runs only through agent_test.ps1 / suite.ps1 / motion.ps1 / flicker.ps1 / g1_gate.ps1; no game test while the user is playing; GPU timers only; failure of an effect = effect OFF; no copying code from the Minecraft pack (re-implement from the described behaviour).

## Status key

- **code**: shader or C++ change, needs a build (build.ps1) and no game run to compile.
- **game**: needs a harness run for A/B, GPU ms or motion numbers.
- **user**: needs the owner.
