## 1. Goal and vision

Goal: ship v0.3.3 as stable final preview that holds Medium at sub 12 ms, High stable no flicker, Ultra usable without strobing.

Vision: keep the bold flat-shaded TY look. No art style change. Fix temporal stability at the structural source, not by hiding it. World-space where it matters, screen-space only where it is reliable.

Definition of done:
- Medium 12 ms or less, High stable, Ultra no full-screen flicker
- No AO cloud behind Ty, no TAA trails, no shadow checkerboard, no fog colour shift, no trees punching through fog
- G1 gate passed on final DLL: 10 min soak + 4 cams + forced fallback
- Zip with dll + launcher + ini + README + PERFORMANCE.md, TY.exe untouched, LAA patched copy only

Non-goals: baking textures, engine draw rewrite, Vulkan/DX, game logic, HD texture authoring.

## 2. Token efficient operating rules

- Max 3 agents at once. Short task files in agents/tasks/*.md. Every step in step log + REPORT.md.
- todo.json is the board. RESUME.md is state. ovsync_all.ps1 -Quick after each step.
- Scripts do measuring. LLMs only for coding and judgement.
- One game at a time. Global lock. Never launch by hand, only via agent_test.ps1 / suite.ps1 / motion.ps1 / flicker.ps1.
- GPU timers only, never wall clock. Timings stable to ~0.1 ms.
- Fallback policy: failure = effect OFF. Never ship a crashing shader.
- Batch several snapshots per run. Do not run game more often than needed.

## 5. What to fix (Batch 1, Day 1)

### T73 AO fade + halo - ao.inl - P0 highest
File: src/agents/ao/ao.inl.md
- Add distance fade: strength 1 at Ty, 0 far. z_start 1500, z_max 3500 world units.
  A_attenuated = lerp(1.0, A_final, exp(-beta*z) * saturate(1-(z-z_start)/(z_max-z_start)))
  Tie to same fog transmittance atmos uses via shared uniform.
- Character not an occluder: capsule mask like GI (u_ch, u_chH 160, u_chR 70). Fixes halo behind Ty.
- Add 3x3 neighbourhood clamp before blend:
  A_clamped = clamp(A_hist, A_min, A_max)
  A_final = lerp(A_current, A_clamped, alpha) alpha 0.85 to 0.95
- Switch per-frame IGN rotation to stable 64x64 blue noise, slow cycle. Reduce noise amplitude when fps low.
- Fix white rim on fern shadows (depth-aware upsample weight check).
Accept: far mountains no AO flicker, no halo behind Ty, ty_strip clean, cost +1 ms max at Medium.

### TAA ghosting + trails - fx.inl - P1 highest
File: src/agents/ao/fx.inl.md (kTAA)
- Keep YCoCg clip, tighten gamma 0.75 to 1.25. Already has variance clip box, verify.
- Add depth-guided history reject: if Dz = abs(z_curr - z_hist)/z_curr > epsilon, blend = 0.
- Adaptive blend by velocity: alpha_adaptive = alpha_base * (1.0 - saturate(|V|*k)). Trust history less under motion.
- Ensure skinned/grass motion handled by clamp, no per-object vectors required.
Accept: no trails on fast Ty turns, grass no ghosting, motion.ps1 temporal 2nd-diff down.

### S1/T82 shadow checkerboard + bright lines - light.inl - P2 high
File: src/agents/ao/light.inl.md
- Texel-align IGN: noise phase scaled by shadow map texel size, not raw screen coords.
- Vogel disk + IGN rotation: check rotation period vs texel grid, avoid 2x2/3x3 regular grid.
- Add depth-weighted cross-bilateral upsample for low-res shadow.
- Fix cascade split bias: slope-scale + receiver-plane bias, consistent across all taps. Root cause bright lines on face/bag unknown, visualise raw vs reconstructed visibility separately.
Accept: no checkerboard on characters, no 1px bright lines, S1 closed.

## 6. What to improve (Batch 2, Day 2)

### Fog GI decouple - atmos.inl - P2 high
- Set lambda_gi = 0.0. Froxel emission = directional sun * phase * sun visibility + ambient sky only.
  L_froxel = L_dir * Phi(theta) * tau_sun + L_ambient_sky
- Keep GI for surfaces, stop GI tinting atmosphere. Fixes fog turning red/white on camera rotate.
- Verify composite mode 3 desat + haze keys still work.

### Trees through fog - pbr.inl + atmos.inl - P2 high
